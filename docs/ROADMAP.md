# رودمپ کامل پروژه

> **هدف:** مینی‌اپ + ربات تلگرام برای پیش‌بینی رقابتی (کریپتو، فوتبال، رویداد)
> با اقتصاد توکن مبتنی بر مهارت.
>
> 📄 مکمل: [`IDEA.md`](./IDEA.md) (طراحی محصول و اقتصاد) · [`DESIGN-SYSTEM.md`](./DESIGN-SYSTEM.md) (رنگ و کامپوننت)
>
> ❌ **فروشگاه در این فاز ساخته نمی‌شود** — به بعد از TGE موکول شد.

# بخش ۱ — استک فنی

| لایه | انتخاب | چرا |
|---|---|---|
| **فرانت (مینی‌اپ)** | React 18 + TypeScript + Vite | استاندارد مینی‌اپ تلگرام |
| **UI** | TailwindCSS + Radix Primitives | سریع، قابل تم‌دهی، دسترس‌پذیر |
| **چارت** | `lightweight-charts` (TradingView) | سبک، مخصوص موبایل، رایگان |
| **State** | Zustand + TanStack Query | ساده، بدون boilerplate |
| **SDK تلگرام** | `@telegram-apps/sdk-react` | هپتیک، تم، MainButton، initData |
| **بک‌اند** | Node.js + TypeScript + Fastify | تایپ مشترک با فرانت، realtime قوی |
| **ریل‌تایم** | WebSocket (`ws`) + Redis Pub/Sub | دوئل و قیمت زنده |
| **صف** | BullMQ (روی Redis) | تسویه‌ی راند، اعلان، تسک زمان‌بندی‌شده |
| **دیتابیس** | PostgreSQL 16 | تراکنش ACID برای دفتر مالی |
| **کش** | Redis 7 | قیمت لحظه‌ای، نشست، ریت‌لیمیت، لیدربورد |
| **ربات** | grammY (TypeScript) | مدرن، تایپ‌دار، همان زبان بک‌اند |
| **پنل ادمین** | React + Refine | سریع ساخته می‌شود |
| **دیپلوی** | Docker Compose → VPS | ساده و کنترل‌شده |
| **مانیتورینگ** | Sentry + Grafana + Loki | خطا و متریک |

### ساختار ریپو (مونوریپو)

```

```

| **Quest** | تسک، استریک، گردونه، بازبینی دوره‌ی عضویت کانال |
| **Referral** | ثبت دعوت، شرط «فعال بودن»، پاداش، گراف |
| **Season** | امتیاز، رتبه، Elo، بسته شدن فصل، اسنپ‌شات |

| **Sports** | دریافت داده‌ی مسابقه، تولید سؤال لحظه‌ای، حل |
| **Admin API** | تمام عملیات پنل با لاگ ممیزی |

### قوانین سخت‌گیرانه‌ی موتور راند

```
t-∞  ← راند باز، شرط پذیرفته می‌شود
t-3s ← ⛔ بسته شدن شرط (buffer ضد آربیتراژ تأخیر)
t0   ← قیمت قفل (Lock) از اوراکل امضاشده
t+D  ← قیمت بسته (Close) از همان اوراکل
       تسویه: تراکنش اتمیک، ایدمپوتنت، غیرقابل تکرار
```
- اگر قیمت در پنجره نرسید → **راند باطل، مبالغ برگردانده می‌شود** (هرگز حدس زده نمی‌شود)
- حداقل مدت راند: **۳۰ ثانیه**
- قیمت Lock و Close همیشه از **یک منبع یکسان**
