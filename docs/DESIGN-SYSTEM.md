## ۲. تایپوگرافی

| نقش | فونت | وزن | اندازه |
|---|---|---|---|
| عنوان صفحه | Vazirmatn / Inter | 800 | 32px |
| عنوان بخش | Vazirmatn / Inter | 700 | 20px |
| متن اصلی | Vazirmatn / Inter | 400–500 | 15px |
| برچسب | Vazirmatn / Inter | 500 | 13px |
| **عدد و قیمت** | **JetBrains Mono** | 600 | متغیر |
| تایمر | JetBrains Mono | 700 | 28px |

**قوانین:**
- تمام اعداد مالی، قیمت‌ها، تایمرها و ضرایب با فونت **مونواسپیس** — تا هنگام تغییر لرزش نکنند (`font-variant-numeric: tabular-nums`)
- اعداد فارسی یا انگلیسی؟ → **انگلیسی** برای قیمت و ضریب، **فارسی** برای متن. یکدست و خواناتر است.

## ۳. RTL

اپ دوزبانه است (فارسی/انگلیسی) و باید کاملاً RTL-aware باشد.

- از `margin-inline-start` به‌جای `margin-left` استفاده شود
- آیکون‌های جهت‌دار (فلش، بازگشت) در RTL آینه شوند
- چارت **هرگز آینه نمی‌شود** — زمان همیشه از چپ به راست است
- اعداد و نمادها همیشه LTR (`dir="ltr"` روی کانتینر عدد)

## ۶. حرکت و بازخورد

| رویداد | بازخورد |
|---|---|
| ثبت پیش‌بینی | هپتیک `medium` + انیمیشن دکمه |
| ۱۰ ثانیه‌ی آخر | تایمر قرمز + هپتیک هر ثانیه |
| برد | هپتیک `success` + کانفتی سبز + صدا |
| باخت | هپتیک `warning` + انیمیشن نرم (بدون تحقیر) |
| تغییر قیمت | فقط رنگ عدد، **بدون** پرش layout |

**قانون:** هیچ انیمیشنی بیش از ۳۰۰ms نباشد. اپ باید سریع حس شود.

## ۷. اصول

1. **چارت قهرمان صفحه است** — همه‌چیز دور آن چیده می‌شود
2. **سبز فقط برای عمل** — هر چیز سبزی باید قابل کلیک باشد
3. **موجودی همیشه دیده شود** — چیپ بالا-راست در تمام صفحات
4. **بدون اسکرول افقی صفحه** — فقط لیست‌ها افقی اسکرول شوند
5. **حالت لودینگ اجباری** — هیچ صفحه‌ای نباید سفید/خالی بماند
6. **آفلاین را مدیریت کن** — اتصال تلگرام موبایل ناپایدار است
